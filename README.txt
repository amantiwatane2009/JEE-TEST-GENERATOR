JEE Main Physics PYQ Simulator — Unified 2019 + 2025 Preview

This test build combines the existing 2025 Class 11 Physics question bank with 200 question crops from the uploaded chapter-wise JEE Main 2019 PDF.

What's new:
- One unified Physics question bank.
- Source selector: All years, 2019 only, or 2025 only.
- 200 2019 questions added with globally unique IDs, year/source metadata, chapter and source PDF page.
- Original question images cropped by column and question-number anchors to preserve equations, diagrams and options.
- Existing custom-length, untimed test mode, chapter selection, answer palette, review flags, scoring, analysis and local history retained.

Important validation notes:
- 2019 answer choices were mapped from the PDF answer-key pages (a/b/c/d -> option 1/2/3/4).
- Explicit numerical answer-key notes (e.g. 3100 and 2 Pascals) are retained as answer strings.
- This is a test build: please spot-check question images and answers before relying on the 2019 bank for scored practice. The PDF's answer keys include bonus/correction notes, and image crops are automatically bounded using question-number positions.
- Question images live in the questions/ folder and use relative paths for static hosting.

Run:
- On Windows, double-click START_TEST.bat if included.
- Or open index.html in a modern browser.
